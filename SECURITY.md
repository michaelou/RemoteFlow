# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using this repository's [GitHub Security Advisories](../../security/advisories/new) form. Do not open a public issue for a vulnerability.

Include a clear description, affected version or commit, reproduction steps, impact, and any suggested mitigation. We will acknowledge the report, investigate it, and coordinate disclosure through the advisory.

## Bug bounty

RemoteFlow does not offer a bug bounty program. We nevertheless appreciate responsible disclosure and will credit reporters where appropriate and with their permission.
